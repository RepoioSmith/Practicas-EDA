# Portafolio de Proyectos de Análisis de Datos

Este repositorio reúne una colección de prácticas y proyectos desarrollados en el área de análisis de datos, ciencia de datos y machine learning. A lo largo de las actividades se exploran distintos procesos del ciclo analítico: adquisición y limpieza de datos, exploración, visualización, modelado predictivo, clasificación, aprendizaje profundo y optimización.

## 📌 Objetivo del portafolio

El propósito de este conjunto de actividades es demostrar el progreso en competencias clave para el análisis de datos y la toma de decisiones basada en información. Entre las habilidades trabajadas destacan:

- Análisis exploratorio de datos (EDA)
- Limpieza y preparación de datasets
- Visualización de información
- Modelos de regresión y clasificación
- Aprendizaje automático y deep learning
- Optimización mediante algoritmos evolutivos
- Resolución de problemas con enfoque empresarial y técnico

---

## 🧭 Panorama general de los proyectos

Los proyectos de este repositorio abarcan múltiples enfoques dentro del análisis de datos:

1. Modelado predictivo para entender relaciones entre variables y prever resultados.
2. Clasificación de datos para resolver problemas binarios y multiclase.
3. Uso de técnicas estadísticas y probabilísticas para interpretar fenómenos.
4. Implementación de modelos de deep learning para tareas de predicción y visión por computadora.
5. Aplicación de algoritmos genéticos para resolver problemas de optimización.
6. Desarrollo de soluciones con enfoque práctico en negocios, inversión y toma de decisiones.

---

## 📚 Tipos de proyectos incluidos

### 1. Análisis y modelado predictivo
Este tipo de proyecto se enfoca en construir modelos que permitan explicar y predecir comportamientos a partir de datos históricos.

- Actividad 1: regresión lineal
- Actividad 3: análisis con datasets relacionados con salud y diamantes
- Actividad 7: modelos lineales y logísticos

### 2. Clasificación y evaluación de modelos
Aquí se trabajó con problemas de clasificación donde el objetivo es asignar una categoría o resultado a partir de características del dataset.

- Actividad 4: clasificación binaria y evaluación mediante métricas como ROC y AUC
- Actividad 11: análisis aplicado a una tienda de ropa

### 3. Modelos estadísticos y probabilísticos
Se incorporaron técnicas más formales para comprender patrones y relaciones en los datos mediante enfoques probabilísticos.

- Actividad 7: modelos bayesianos y regresión logística

### 4. Deep learning y redes neuronales
Se exploraron modelos modernos de aprendizaje automático para tareas de predicción y reconocimiento de patrones.

- Actividad 10: regresión simple con TensorFlow
- Actividad 12: clasificación de imágenes de perros y gatos
- Actividad 13: integración de soluciones de machine learning en un entorno visual o web

### 5. Optimización y algoritmos evolutivos
Se estudiaron técnicas inspiradas en procesos naturales para resolver problemas complejos de búsqueda y optimización.

- Actividad 15: introducción a algoritmos genéticos
- Actividad 16: desarrollo de soluciones con algoritmos genéticos
- Actividad 17: comparación entre enfoques genéticos y no genéticos
- Actividad 20: aplicación a problemas de optimización como el problema del viajero

### 6. Soluciones orientadas a negocio
Algunos ejercicios simulan escenarios reales donde el análisis de datos apoya decisiones de negocio, inversión o planificación.

- Actividad 2: casos empresariales relacionados con pintura, inmobiliario y retail
- Actividad 18: desarrollo de un asesor de inversiones

### 7. Visualización y presentación de resultados
Además del análisis técnico, se trabajó en la comunicación visual de resultados para que los hallazgos sean más claros y útiles.

- Actividad 13: uso de una página web para presentar resultados de forma interactiva
